# Bali 2026 Trip

Публичная семейная витрина маршрута на Бали в октябре-ноябре 2026.

URL после деплоя GitHub Pages:

```text
https://timurgromov.github.io/bali-2026-trip/
```

## Стек

- Astro
- TypeScript
- Leaflet + OpenStreetMap
- GitHub Pages
- Один источник маршрута: `src/data/trip.json`

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Правило данных

Маршрут, карта и дневной план не редактируются отдельно. Любое изменение баз, дат, переездов, точек карты, описаний или порядка маршрута сначала вносится в `src/data/trip.json`, после чего сайт пересобирается.

После изменения маршрута или жилья нужно проверить все представления этой информации: hero, блок «Сейчас», базы, дни, карту, пины, переезды, справочник мест, логистику и открытые решения. Если связь с другой частью маршрута неочевидна, её нельзя угадывать — сначала требуется уточнение пользователя.

Маршрут считается по переездам и точкам проживания: 7 точек проживания и 6 смен жилья между ними. Основная последовательность: Canggu, Gili Trawangan, Gili Air, отдельный возврат в Canggu, частная семейная вилла в Umalas, Ubud и Uluwatu.

Островная логистика полностью отражает фактический сценарий: `Canggu -> Padang Bai -> Gili T -> Gili Air -> Gili Meno (днём) -> Gili Air -> Padang Bai -> Canggu`. На Trawangan две ночи, на Air две ночи, Meno — дневной выезд без ночёвки. 26 октября целиком отведено на возврат в Чангу, чтобы 27 октября провести день рождения без дороги. Лишних островных веток в маршруте нет.

Карта содержит не только базы, но и названные места из текущего плана: Pererenan, Potato Head Beach Club, La Brisa, черепашье побережье Gili T, Gili Meno с BASK и подводными статуями, SANDS, Mowie’s, Tegallalang, Monkey Forest, Mount Batur, Single Fin и SUKA. В карточках дней, справочнике мест и карточках баз для каждого публичного места с известной точкой есть прямой переход в Google Maps, чтобы на телефоне сразу построить маршрут; нераспознанный `TBD` не маскируется под навигационную точку. Карта маршрута остаётся отдельным интерактивным экраном.

В карточках баз хранятся только публичные варианты жилья и их ссылки. Семейная вилла сестры 30 октября – 1 ноября остаётся частным блоком: её название и точный адрес, контакты лодочников, документы и номера бронирований в репозиторий не попадают.

## План по дням

Каждый день открывается и сворачивается целиком по шапке карточки. В развёрнутом виде видны официальный план, места, тайминг, запасной сценарий, еда/отдых, важные ограничения и ссылки Google Maps. Выбранное состояние каждого дня запоминается в текущем браузере; выбор даты и действие «Открыть день» разворачивают нужную карточку. На публичной статической странице нет личного локального слоя и редактирования маршрута в браузере.

После любых изменений контента или верстки нужно просмотреть всю страницу на desktop и mobile, а не только изменённый блок.

В публичный repo нельзя добавлять PNR, паспорта, номера билетов, точные приватные адреса, скриншоты бронирований, PDF-билеты и другие приватные документы.
