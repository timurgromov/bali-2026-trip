# Bali 2026 Trip

Публичная семейная витрина маршрута на Бали в октябре-ноябре 2026.

URL после деплоя GitHub Pages:

```text
https://timurgromov.github.io/bali-2026-trip/
```

## Стек

- Astro
- TypeScript
- Leaflet + OpenStreetMap
- GitHub Pages
- Один источник маршрута: `src/data/trip.json`

## Команды

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Правило данных

Маршрут, карта и дневной план не редактируются отдельно. Любое изменение баз, дат, переездов, точек карты, описаний или порядка маршрута сначала вносится в `src/data/trip.json`, после чего сайт пересобирается.

После изменения маршрута или жилья нужно проверить все представления этой информации: hero, блок «Сейчас», базы, дни, карту, пины, переезды, справочник мест, логистику и открытые решения. Если связь с другой частью маршрута неочевидна, её нельзя угадывать — сначала требуется уточнение пользователя.

Маршрут считается по переездам и точкам проживания: 7 точек проживания и 6 смен жилья между ними. Основная последовательность: Canggu, Indica Luxury Villa Ubud в Убуде, отдельный возврат в Canggu, частная семейная вилла в Umalas, Gili Trawangan, Gili Air и Uluwatu.

Первый блок Убуда полностью отражает фактический сценарий: `Canggu -> Indica Luxury Villa Ubud (22-26 Oct) -> Mount Batur (24 Oct, туда-обратно) -> Canggu`. На Indica Luxury Villa Ubud четыре ночи; после Batur 24 октября возвращаемся в ту же виллу, а 26 октября — в Чангу, чтобы 27 октября провести день рождения без дороги. После свадьбы зафиксирован только каркас: Gili Trawangan 1-3 Nov, Gili Air 3-5 Nov, Gili Meno днём 4 Nov и Uluwatu 5-7 Nov. Билеты лодок, жильё и конкретная программа этого блока помечены `TBD`.

На обратной пересадке 8 ноября выбран ближний безопасный сценарий без поездки в центр Чэнду: после прилёта в TFU в 06:10 — Line 18 до станции Саньча, короткий DiDi к входу №1 в парк Всемирной садовой выставки, компактный круг через Сад Чэнду и башню Цзиньюнь, ранний обед у метро и отправление обратно не позже 12:10. Целевое возвращение в TFU — 12:35-12:50, крайний целевой предел — 13:15 перед вылетом в 16:45. Выход разрешён только после фактического прохождения погранконтроля, при наличии посадочного TFU -> SVO и багажной бирки SVO; иначе план Б — остаться в аэропорту.

Карта содержит не только базы, но и названные места из текущего плана: Pererenan, Potato Head Beach Club, La Brisa, Nuanu Creative City, Splash Waterpark Bali, Cemagi Beach, Indica Luxury Villa Ubud, Mount Batur, Padang Bai, Gili Trawangan, Gili Air, Gili Meno и Uluwatu. В карточках дней, справочнике мест и карточках баз для каждого публичного места с известной точкой есть прямой переход в Google Maps, чтобы на телефоне сразу построить маршрут; у каждой выбранной базы также есть явная ссылка на бронирование. Нераспознанный `TBD` не маскируется под навигационную точку. Карта маршрута остаётся отдельным интерактивным экраном.

Интерактивная карта остаётся картой маршрута по Бали и Гили, чтобы не ломать её масштаб одной удалённой транзитной остановкой. Пять точек транзита — станция Саньча, вход №1, Сад Чэнду, башня Цзиньюнь и Linqi Vitality City — хранятся в том же `trip.json`, показываются в карточке 8 ноября и справочнике мест и имеют прямые ссылки Google Maps. У каждого транспортного участка также есть отдельная ссылка построения маршрута; китайские названия нужно сохранить офлайн, потому что Google-сервисы в Китае могут быть недоступны.

В блоке возвращения в Canggu: 28 Oct — массаж утром и Nuanu после обеда; 29 Oct — Splash Waterpark Bali к 09:10, обед и отдых дома, затем Cemagi Beach к 16:00. Это рабочий тайминг с запасом, а входные билеты, часы работы, волны и семейные правила подтверждаются ближе к поездке.

В карточках баз хранятся только публичные варианты жилья и их ссылки. Семейная вилла сестры 30 октября – 1 ноября остаётся частным блоком: её название и точный адрес, контакты лодочников, документы и номера бронирований в репозиторий не попадают.

## План по дням

Каждый день открывается и сворачивается целиком по шапке карточки. В развёрнутом виде видны официальный план, места, рабочий тайминг по часам, дорога с расстоянием/временем/транспортом, запасной сценарий, еда/отдых, важные ограничения и ссылки Google Maps. Время поездок — плановое окно с запасом, а не выдаваемое за подтверждённую бронь расписание. Выбранное состояние каждого дня запоминается в текущем браузере; выбор даты и действие «Открыть день» разворачивают нужную карточку. На публичной статической странице нет личного локального слоя и редактирования маршрута в браузере.

После любых изменений контента или верстки нужно просмотреть всю страницу на desktop и mobile, а не только изменённый блок.

В публичный repo нельзя добавлять PNR, паспорта, номера билетов, точные приватные адреса, скриншоты бронирований, PDF-билеты и другие приватные документы.
