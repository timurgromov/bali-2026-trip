# Состояние раскрытия дней — 21 сентября 2026

## Решение

Дневные карточки в публичном маршруте сворачиваются и раскрываются целиком по шапке. В закрытом виде видны дата, база и название дня; в открытом — весь официальный план с местами, Google Maps и деталями.

## Хранение

В Local Storage текущего браузера сохраняется только состояние «раскрыт/свёрнут» для каждого дня. Это не личная заметка, не маршрутные данные и не способ изменить `src/data/trip.json`.

## Поведение переходов

Быстрый выбор даты и ссылка «Открыть день» из блока «Сейчас» раскрывают целевую карточку. Прямой адрес `#day-N` раскрывает её при первом переходе, когда для этого дня ещё нет сохранённого выбора; затем приоритет остаётся за ручным состоянием пользователя.
