# Личные записи по дням — 13 сентября 2026

## Решение

В статическом семейном маршруте добавлен личный слой в карточки дней: заметка, тайминг, checklist и ссылки/контакты. Он не редактирует `src/data/trip.json`, не меняет карту, базы или переезды.

## Хранение

Данные хранятся только в Local Storage текущего браузера. В интерфейсе доступны экспорт и импорт JSON для переноса между устройствами, а также явная очистка локальных записей.

## Граница данных

Личные значения не попадают в исходники, Git, GitHub Pages или общий маршрут. Для общего изменения даты, базы, маршрута или места всё ещё используется `src/data/trip.json` с полной проверкой зависимых поверхностей.
